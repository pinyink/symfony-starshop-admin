# Roadmap — StarShop

## Current Milestone (v1.0)
- Core Symfony 7 setup and modular architecture.
- Product management with categorization, file uploads, currency formatting, and datatables.
- User management and profile configuration.
- Role-Based Access Control (RBAC) via `olivier127/rbac-bundle`.
- Geospatial/spatial support with Doctrine Spatial.

## Future Milestones & Planned Improvements
- **v1.1: Automated Testing Expansion**
  - Add functional/integration tests for controllers and repositories.
  - Expand test coverage beyond form data transformers.
- **v1.2: Security & Access Control Hardening**
  - Refine `security.yaml` access control rules.
  - Implement comprehensive permission checks across all administrative endpoints.
- **v1.3: Advanced E-Commerce Features**
  - Inventory tracking, order management, and customer checkout flows.
