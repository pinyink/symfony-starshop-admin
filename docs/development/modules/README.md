# Modules Documentation — StarShop

StarShop is organized into modular components under `src/Controller/`, `src/Entity/`, `src/Repository/`, `src/Form/`, and `templates/`.

## Detected Significant Modules
1. [Product Module](product.md) — Product catalog, categorization, file uploads, price formatting, datatables.
2. [User Module](user.md) — User account management, credentials, profile customization.
3. [RBAC Module](rbac.md) — Roles and permissions management via `olivier127/rbac-bundle`.
4. [Banner Module](banner.md) — Promotional banner management with image upload and sorting.
