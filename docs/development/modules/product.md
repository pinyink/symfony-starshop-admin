# Product Module

## Overview
The Product module manages merchandise listings, pricing transformations, category associations, file uploads, and server-side data tables.

## Components
- **Controller:** `src/Controller/ProductController.php`
- **Entity:** `src/Entity/Product.php`
- **Repository:** `src/Repository/ProductRepository.php`
- **Form:** `src/Form/ProductType.php` (utilizing `RupiahTransformer`)
- **Templates:** `templates/product/`
