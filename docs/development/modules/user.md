# User & Profile Module

## Overview
The User and Profile module handles user account administration, password management, and profile editing.

## Components
- **Controllers:** `src/Controller/UserController.php`, `src/Controller/ProfilController.php`, `src/Controller/SecurityController.php`
- **Entities:** `src/Entity/User.php`
- **Repositories:** `src/Repository/UserRepository.php`
- **Forms:** `src/Form/UserType.php`, `src/Form/ProfilType.php`, `src/Form/ResetPasswordType.php`
- **Templates:** `templates/user/`, `templates/profil/`, `templates/security/`
