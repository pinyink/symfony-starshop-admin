# RBAC Module

## Overview
The Role-Based Access Control (RBAC) module manages roles, permissions, and security bindings using `olivier127/rbac-bundle`.

## Components
- **Controllers:** `src/Controller/RoleController.php`, `src/Controller/PermissionController.php`
- **Entities:** `src/Entity/Role.php`, `src/Entity/Permission.php`
- **Templates:** `templates/role/`, `templates/permission/`
